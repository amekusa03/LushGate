1. システム開発の背景と目的

本システム「LushGate（ラッシュゲート）」は、商用電源やWi-Fiインフラが存在しない山間部・露地畑（約2坪）において、太陽光発電＋バッテリー駆動で完全自律稼働する自動散水システムです。

複雑・高価な土壌水分センサーの導入を避け、「直近24時間の降雨実績が一定基準に満たない日のみ散水を行う」という明快な制御ロジックを採用します。 現場での保守・設定変更時には、スマートフォンと1対1で接続できるオンデマンドWi-Fi AP & mDNS Web UIを提供し、使いやすさと超低消費電力運用の両立を実現します。

2. システム全体構成

システムは以下の電源系・制御系・駆動系・センサー系で構成されます。

【ソーラー電源系】 [ 太陽光パネル 10W ] ──> [ 充放電コントローラ ] ──> [ LiFePO4 バッテリー 12V 6Ah ] │ (12V出力) ┌────────────────┴────────────────┐ ▼ ▼ [ 3.3V DC-DC降圧 ] [ 3.0V DC-DC降圧 / 電池 ] │ │ ▼ │ 【制御系】 [ ESP32-C3 (3.3V給電) ] ──(3.3V駆動)──> [ フォトカプラ (1次側) ] │ (完全絶縁) ▼ [ 12V メカリレー (2次側: 12V系) ] │ │ │ │ ▼ ▼ 【センサ・駆動】│ [ BOOTボタン/LED ] [ 灯油ポンプ 3V (200Lタンク) ] ▼ │ [ J3Y増幅 雨滴センサー ] ▼ [ 畝ドリップ散水管 (畑2坪) ]

3. 機能要件一覧 (Functional Requirements)

本システムで提供する全機能要件を以下に定めます。

要件ID 機能分類・名称 要件詳細仕様 重要度
FR-01 低消費電力雨量監視
(Deep Sleep)		 ・設定されたスリープ周期（デフォルト3分、1〜15分で設定可）でDeep Sleepから復帰。
・GPIO1からJ3Y増幅回路に数msのパルス給電を行い、OUT端子(GPIO0)をADC測定。
・閾値以上の導通を検知した場合、累積降雨時間（分）に加算して再びDeep Sleepへ移行。 		必須
FR-02 散水判定＆
デューティ駆動		 ・毎朝の設定時刻（デフォルト07:00、00:00〜23:59）に散水判定を実施。
・過去24h累積降雨が閾値（デフォルト60分）以上なら散水スキップ。
・閾値未満なら、ポンプの過熱防止のため「3分ON・2分OFF」デューティにて正味10分（実時間約17分）の自動散水を実施。
・判定・散水結果をNVS履歴へ記録し、カウンタをリセット。 		必須
FR-03 オンデマンド
Wi-Fi SoftAP		 ・常時Wi-FiはOFF（省電力）。現場で `BOOTボタン (GPIO9)` を2秒長押しすることでSoftAPを起動。
・SSID: `LushGate-XXXX`（MAC識別付き）、認証: オープンまたはWPA2。
・稼働中はオンボードLED（GPIO8）を点滅表示。 		必須
FR-04 mDNS名前解決 ・IPアドレス（192.168.4.1）の直接入力不要で、ブラウザから `http://lushgate.local` でアクセス可能とする。 必須
FR-05 Webによる
1タップ時刻補正		 ・Web UIダッシュボード上に「📱 スマホ時刻と同期」ボタンを配置。
・接続したスマホブラウザの現在時刻（UNIX Epoch）をPOST送信し、ESP32内蔵RTCを1タップで即時同期。 		必須
FR-06 Web設定管理 &
NV（NVS）保存		 ・散水時刻、監視周期、雨量スキップ閾値、ADC判定閾値、ポンプデューティ（ON/OFF/総時間）、APタイムアウトをWebフォームから変更可能。
・設定値はESP32内蔵NVS（不揮発性メモリ）へ保存し、電源断・Deep Sleep後も保持。 		必須
FR-07 散水履歴のWeb参照 &
CSVダウンロード		 ・過去60回分の判定結果（散水実施／雨スキップ／手動／異常）、24h雨量、実ポンプ駆動時間をNVSリングバッファに保存。
・Web上で一覧表示し、ボタン1つでCSVファイル（`lushgate_history.csv`）としてダウンロード可能。 		必須
FR-08 手動散水テスト &
センサー即時測定		 ・配線・水流テスト用に「30秒手動テスト散水（安全自動停止付き）」ボタンを提供。
・雨センサーの生電圧（mV）と判定状態をリアルタイムで画面上に取得・表示。 		推奨
FR-09 AP自動タイムアウト
(バッテリー保護)		 ・Web接続後、最後の操作から設定時間（デフォルト5分）無操作が続いた場合、または画面上の「スリープへ」ボタン押下時に自動でAPを停止しDeep Sleepへ復帰。 必須

4. 非機能要件 (Non-Functional Requirements)

項目 要件詳細
消費電力・電源自律性 ・Deep Sleep待機時消費電流: 数十μAレベル（雨センサー待機電流は完全ゼロ）。
・1日あたりの消費電力量: 散水1回（10分稼働）含めて1Wh未満。
・10Wソーラーパネル＋12V 6Ah LiFePO4バッテリーにより、無日照が1週間以上続いても稼働を継続可能。
電極腐食対策 (高信頼性) ・SUS製電極プレートに対し、サンプリング毎に印加極性（A→B / B→A）を反転させ電気分解を抑制。
・印加時間を1回あたり5ms以内とし、測定完了直後に両ピンを完全Hi-Z（浮動状態）にして直流印加を遮断。
電気的絶縁 & 給電設計 ・ESP32制御系: ソーラー発電機の 5V USB出力 から直接給電（降圧コンバータ不要・USB直結）。
・ポンプ駆動系: 単一形乾電池2本（DC 3.0V） による完全独立給電。
・リレー接点部（COM/NO）により、マイコン系とポンプ系は 電源元およびGNDを含めて完全に物理的分離（アイソレーション） され、モーターの逆起電力ノイズ・突入電流・電圧ドロップによるマイコンの誤動作・破損を根本的に遮断します。
データ保全性 ・設定値および散水履歴（過去60回分）はFlashメモリ（NVS領域）に保持され、バッテリー交換や完全放電時にもデータ消失しない設計。
対応端末 ・スマートフォン（iOS Safari, Android Chrome）およびPC（Windows, macOS）の主要Webブラウザに対応（レスポンシブSingle Page Web UI）。

5. ハードウェア I/O ピンアサイン仕様

GPIO 機能識別名 I/O / 属性 論理 接続対象・用途
GPIO0 `PIN_RAIN_OUT` ADC1_CH0 / Input アナログ入力 J3Y増幅 雨滴センサー信号出力 (OUT端子)
GPIO1 `PIN_RAIN_POWER` Digital Output プッシュプル/Hi-Z 雨センサー給電パルス制御 (VCC / 腐食・待機電力防止)
GPIO7 `PUMP_CTRL` Digital Output Active High JQC-3F 3Vリレーモジュール制御（リレーON）
GPIO8 `STATUS_LED` Digital Output Active Low オンボードLED（APモード時点滅インジケータ）
GPIO9 `USER_BUTTON` Digital Input Active Low (Pull-up) BOOTボタン（2秒長押しでWi-Fi AP起動）

  4. 本システム要件定義書（`docs/requirements_definition.html`）

7.2 検収基準

  • [ ] BOOTボタン2秒長押しにより、Wi-Fi SoftAPおよびmDNS（`http://lushgate.local`）が起動すること。
  • [ ] スマホブラウザからWeb画面にアクセスし、「スマホ時刻と同期」でESP32 RTC日時が正常に補正されること。
  • [ ] Web画面から散水時刻・デューティ時間・閾値を変更し、再起動後も設定値が保持されていること（NVS保存確認）。
  • [ ] 雨センサーに水分を与えた際、測定電圧が上昇し「降雨検知」として積算されること。
  • [ ] 毎朝の判定時刻において、累積降雨60分以上の場合は散水スキップ、未満の場合はリレーがデューティ駆動（3分ON/2分OFF）すること。
  • [ ] 判定および散水結果がWeb画面の履歴テーブルに記録され、CSVファイルとして正常にダウンロードできること。
  • [ ] AP起動後、5分間の無操作で自動的にDeep Sleepへ安全に復帰すること。
